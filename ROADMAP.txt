EXPENSE TRACKER - DETAILED PLAN OF ACTION
==========================================

GOAL
Use the ExpenseTracker MCP server for my own daily expenses and reports (mail),
then turn it into an Android edge app that other people install and use
offline, with all data staying on their own phone.

WORKING FOLDER (all changes happen here)
D:\MCP\Project\ExpenseTracker-LocalMCP

CURRENT STATE
- FastMCP server + local SQLite database (expenses.db) + categories.json
- Tools working: add_expense, list_expenses, summarize, delete_expense,
  get_home_currency, set_home_currency
- Every expense has a currency (ISO code). Default = home currency (INR).
- Old entries were upgraded to INR automatically.

KEY DESIGN RULES
1. Rupee (INR) for India. Other countries use their own currency.
2. Each user has ONE home currency. An expense uses it unless a different
   currency is stated (example: "$5 coffee" while travelling).
3. Totals are never mixed across currencies.
4. Tool names, parameters and DB schema stay identical between the PC server
   and the Android app, so nothing gets rewritten.
5. An MCP server cannot be shipped to other people's phones as it is. The
   phone app will contain the same tools and a local database inside it.

RISKS AND NOTES
------------------------------------------------------------
- Lost phone without backup = lost data. Export and backup are important.
- SQLite does not sync across devices. Add cloud sync only later, as optional.
- Currency conversion is NOT included. A later step could add optional
  conversion in reports.
- Do not change the schema after Phase 2 without writing a migration.
- Keep expenses.db with real data out of GitHub.
